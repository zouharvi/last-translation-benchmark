🪨 Last Translation Benchmark

A large-scale effort to collect difficult-to-translate inputs

This platform gathers inputs (text, video, audio, images, documents) that are challenging for modern machine translation systems.

Contributors submit these inputs alongside machine translation outputs and a verification rule. Approved contributions are eligible for inclusion in upcoming research publications.
